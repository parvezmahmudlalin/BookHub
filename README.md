# BookHub - Online Book Borrowing Platform

## Purpose

BookHub is an online book borrowing platform where users can browse books, search by title, filter by category, view book details, and manage their profiles through a secure authentication system.

## Live URL

https://book-hub-ashy-one.vercel.app

## Key Features

* User Registration and Login
* Google Authentication
* Private Routes
* Browse All Books
* Search Books by Title
* Category Filtering
* View Book Details
* Borrow Books
* User Profile Management
* Update Profile Information
* Responsive Design
